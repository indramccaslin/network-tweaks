# Network Tweaks

Optimize network stack for lower latency in games & online apps.

## Features
- TCP congestion control (BBR/CUBIC/Westwood/BBR2)
- TCP tuning (low latency, fastopen, autocorking, metrics)
- Buffer sizing (rmem/wmem)
- QoS (fq/fq_codel/cake)
- Game-only latency boost (notsent_lowat, busy poll)
- DNS config
- MTU setting
- Game list auto-apply
